# Harbor Manga Repo

مستودع GitHub جاهز لجمع مصادر مانجا عربية وإنجليزية لـ Harbor.

## الحالي
- 3asq: إضافة مخصصة بالعربية مع جلب الفصول عبر AJAX.
- MangaDex: إضافة مخصصة بالعربية باستخدام API.
- MangaLik: إعداد selectors؛ قد يتأثر بمكافحة الروبوتات.

## مهم
Harbor أعلن في يوليو 2026 أن المانجا أصبحت BYOS مع دعم custom manga plugins، لذلك صيغة repository الموحدة ليست مثبتة هنا بدون توثيق API رسمي يمكن التحقق منه.

ارفع هذا المستودع إلى GitHub، ثم استخدم آلية repo التي يدعمها إصدار Harbor لديك.
